Today I learned the fundamentals of Python lists and list methods, which are one of the most important data structures in Python. Lists are ordered, mutable collections that can store multiple values including mixed data types like integers, strings, and booleans.

I explored how to access list elements using indexing and slicing. Indexing starts at 0, meaning the first element is accessed with list[0], while negative indexing allows access from the end using values like -1. I also learned slicing techniques such as list[1:4] to extract a range and list[::2] to skip elements.

In list methods, I practiced append(), insert(), and extend() for adding elements, and understood when to use each. I also studied remove(), pop(), sort(), reverse(), count(), and index() for modifying and analyzing lists.

A key insight was performance differences: append() is fast, while insert() is slower because it shifts elements. This is important when working with large datasets.

Overall, I understood how lists behave in memory, how indexing works as an offset, and how different operations affect performance. This foundation is essential for problem-solving and Data Structures & Algorithms practice.
