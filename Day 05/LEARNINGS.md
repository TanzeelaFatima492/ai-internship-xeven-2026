
# Day 5: Introduction to Machine Learning Concepts

## Topics Learned

### Supervised Learning
- Learns from labeled data.
- Predicts outputs for new inputs.
- Examples:
  - Spam detection
  - House price prediction

### Unsupervised Learning
- Learns patterns from unlabeled data.
- Examples:
  - Customer segmentation
  - Anomaly detection

### Reinforcement Learning
- Learns through trial and error using rewards.
- Components:
  - Agent
  - Environment
  - Actions
  - Rewards
- Examples:
  - Robotics
  - Game AI
  - Recommendation systems

### Regression
- Predicts continuous numerical values.
- Examples:
  - House prices
  - Sales forecasting
  - Temperature prediction

### Classification
- Predicts discrete categories.
- Examples:
  - Spam detection
  - Disease diagnosis
  - Image classification

### Decision Trees
- Flowchart-like supervised learning algorithm.
- Uses branching decisions.
- Components:
  - Root node
  - Internal nodes
  - Leaf nodes
- Can solve both classification and regression problems.

## Key Insight

Machine learning algorithms learn patterns from data to make predictions or decisions without explicit programming for every scenario.
